## 📌 Project Overview

**Nexa Digital Agency** is a modern business landing page concept created to demonstrate professional front-end development, responsive layouts, and contemporary website design.

The website presents a fictional digital agency through a distinctive dark-green and lime visual identity, structured service cards, an agency introduction, a project process, testimonial examples, and a contact section.

The project focuses on creating a clear user journey—from the first impression to exploring services and reaching the contact form—while maintaining a consistent visual style across different screen sizes.

> **Project type:** Front-end portfolio project  
> **Development focus:** Semantic HTML, modern CSS, responsive design, accessibility, and UI presentation.

## ✨ Key Features

- **Premium visual identity** — A dark-green palette, lime accents, refined typography, and consistent spacing.
- **Professional hero section** — A strong headline, supporting copy, and prominent call-to-action links.
- **Service showcase** — Structured cards highlighting web design, brand identity, and digital development.
- **Agency introduction** — A dedicated About section explaining the agency's approach and values.
- **Step-by-step process** — A clear presentation of the project workflow.
- **Testimonial section** — Example client feedback layouts demonstrating social-proof design.
- **Contact section** — A structured enquiry form with clearly labelled fields.
- **Responsive navigation** — A compact mobile menu and clear desktop navigation.
- **Responsive layouts** — CSS Grid, Flexbox, and media queries for desktop, tablet, and mobile.
- **Accessible interaction states** — Visible keyboard focus indicators and reduced-motion support.
- **Reusable styling system** — CSS custom properties for colors, spacing-related styling, borders, and shadows.

## 🎨 Design Highlights

**Visual direction:** Modern, minimal, confident, and business-focused.

- **Primary background:** Deep forest green
- **Accent color:** Lime green
- **Supporting surfaces:** Warm off-white and soft neutral green
- **Typography:** Manrope and DM Sans
- **Layout approach:** Spacious sections, clear hierarchy, and reusable components

The design aims to balance visual character with readability, keeping navigation, service information, and contact actions easy to find.

## 📱 Responsive Design

The layout adapts to different viewport widths through CSS media queries.

- **Desktop:** Multi-column hero, service cards, and spacious content sections.
- **Tablet:** Adjusted column proportions, spacing, and visual elements.
- **Mobile:** Single-column content, compact navigation, and mobile-friendly form layouts.

For best results, test the page using your browser's responsive device toolbar as well as on a real mobile device.

## ♿ Accessibility Considerations

Accessibility is considered through semantic page sections, labelled form controls, visible keyboard focus, responsive text layouts, and reduced-motion preferences.

This is an ongoing consideration rather than a claim of full accessibility certification. Further testing with keyboard navigation, screen readers, and contrast-checking tools is recommended.
